# Stephen Varghese — Creative Portfolio

A static portfolio for a Generative AI Creative Producer and Creative Technologist. The featured case study documents the production decisions behind an AI-generated ferry sequence: shot breakdown, storyboard direction, isolated layouts, four generated character plates, final composite generation and image-to-video direction.

The hero pairs Stephen's portrait with a moving wall of selected work. Throughout the case study, compact editorial stages keep storyboards, generated images and video sharp instead of enlarging them to fill the viewport.

## Publish on GitHub Pages

1. Upload every file and folder in this package to the root of the `stephen-varghese-portfolio` repository.
2. Commit the changes to the `main` branch.
3. In **Settings → Pages**, use **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the Pages deployment to finish, then open:
   `https://stephenjacobvarghese.github.io/stephen-varghese-portfolio/`

No build tools or paid hosting are required. The site uses plain HTML, CSS and JavaScript.
